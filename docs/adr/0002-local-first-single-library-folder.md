# Local-first, with all data and media in one library folder

The app runs on one Mac with no server and no sync. All data and all media, including Documentary footage, are copied into a single portable library folder. The brand has one person on one machine, and one self-contained folder is the simplest thing to back up, move, and reason about.

## Considered Options

- **Cloud-backed or synced**: rejected for now. There is only one user, and syncing video is slow and expensive.
- **Reference large video files in place on external drives**: rejected. The founder preferred one self-contained library over files spread across drives.

## Consequences

Footage makes the library very large, so it will often live on an external drive. The app must open a library from any location and must handle the library's drive being disconnected.
